## P03｜产品族概览

### 一套为文博展示而设计的交互信息终端

交互信息终端不是把普通显示屏放进展厅，而是把展柜、墙面、岛台、护栏和信息带中的静态信息，转化为可分层阅读、可触摸探索、可多人共览、可持续更新的展陈信息界面。

产品族以四种观看关系构成清晰分工：

| 标准产品 | 产品角色 | 主要解决的问题 | 典型观看关系 |
|---|---|---|---|
| 21.5寸常规屏 | 精读 | 让观众读完一件文物的图文、铭文和细节 | 1人近距离阅读 |
| 29寸条屏 | 探索 | 让观众通过横向浏览、旋转和滑动看懂一处细节 | 1人操作，旁观可读 |
| 43寸常规屏 | 大体验信息交互 | 承载内容较重的大画幅互动，可拓展多机联动 | 单机1—4人；2—3台可联动协作 |
| 43寸条屏 | 共览 | 让多人同时浏览一组文物、时间线或关系图谱 | 2—3人并行浏览 |

### 产品族共同亮点

- 产品族覆盖全高清至4K显示层级，不同产品采用与自身画幅和内容任务匹配的标准分辨率。
- 全系采用G+G电容触摸方案，最多支持10点触摸。
- 采用国产ARM架构处理器、OpenHarmony操作系统和团结引擎交互开发框架。
- 支持视频、图文、多图、查询、三维模型、常亮信息展示和视觉导视。
- 支持网络、音频、存储和项目级互动外设拓展。
- 以标准工程模组为基础，可形成多种定制外观和安装形态。

## P04｜国产技术路线

### 面向文博展示及信创项目应用

产品族以国产软硬件协同为基础，为展馆长期运行、项目定制和后续维护建立统一技术底座。

| 层级 | 产品路线 | 对客户的价值 |
|---|---|---|
| 显示与触控 | 国产显示模组、G+G电容触摸 | 形成统一的显示与交互基础 |
| 计算平台 | 国产ARM架构处理器 | 覆盖基础信息展示到4K复杂交互 |
| 操作系统 | OpenHarmony 5.0.0.71 | 面向国产化和信创项目环境 |
| 交互开发 | 团结引擎 | 支持图文、视频、三维和互动程序开发 |
| 内容与服务 | 文博内容适配、系统集成、持续更新 | 让同一硬件平台适配不同展项 |

技术路线的重点不是展示零件品牌，而是保证产品拥有清晰的软件基线、配置边界和持续维护方式。标准产品能力、可选配置和定制项目分别管理，避免把一次性项目功能误认为全系默认能力。

## P05｜推荐选型指南

### 四步选择合适的终端

#### 第一步：看内容

- 单件文物、长篇图文、铭文纹饰：优先21.5寸常规屏。
- 三维细节、横向长图、短任务互动：优先29寸条屏。
- 高精图像、复杂三维、内容较重的大体验：优先43寸常规屏。
- 时间线、长卷、器物序列、多人并列阅读：优先43寸条屏。

#### 第二步：看空间

确认可用宽度、高度、观看距离、安装方向、维护空间以及电源和网络条件。先以工程模组OD完成空间预留，再根据外壳与安装形式确认最终整机尺寸。

#### 第三步：看互动拓展

根据项目需要决定是否增加摄像头、扫码器、读卡器、NFC、旋钮、传感器、定向音频、多屏同步或其他外接硬件。

## P06｜产品型号编制规则

### 型号要让人一眼读懂

建议采用以下型号结构：

```text
BJTT - 显示尺寸 - 产品形态 - 分辨率等级 - 产品版本
```

| 字段 | 表达方式 | 示例说明 |
|---|---|---|
| BJTT | 产品族统一前缀 | 文博交互信息终端产品族标识 |
| 显示尺寸 | 215 / 290 / 430 | 分别对应21.5、29和43英寸 |
| 产品形态 | S / B | S为常规标准屏，B为条形屏 |
| 分辨率等级 | 2K / 4K | 标识该产品所属显示层级 |
| 产品版本 | A / B / C | 结构、电气或关键配置发生变化时递增 |

建议型号示例：

| 产品 | 建议型号 |
|---|---|
| 21.5寸常规屏 | BJTT-215-S-2K-A |
| 29寸条屏 | BJTT-290-B-2K-A |
| 43寸常规屏 | BJTT-430-S-4K-A |
| 43寸条屏 | BJTT-430-B-4K-A |

型号只表达产品族、尺寸、形态、分辨率和主版本。内存、存储、系统镜像和项目配置通过配置单管理，不继续堆入主型号。

## P08｜21.5寸常规屏：精读

### 让观众站定读完一件文物

21.5寸常规屏是一款紧凑型近距离交互终端，适合部署在展柜前缘、墙龛、展台斜面或独立小型支架中。它将一件文物的名称、年代、用途、铭文、纹饰和关联器物组织成清晰的分层内容。

### 推荐内容

- 单件文物详情。
- 铭文释读与局部放大。
- 纹饰结构和工艺说明。
- 文物相关器型和历史关系。
- 图文档案、人物故事和专题查询。

### 推荐交互

点击、翻页、局部放大、图层切换、少量横向浏览和三维模型查看。基础操作应做到低学习成本，观众进入界面后能够迅速理解“这里讲什么、下一步可以做什么”。

>
> - 形式：黑白等距场景图。
> - 内容：观众站在展柜前，屏幕位于自然下垂手臂的触控范围；实物文物与数字详情建立视线对应。

## P10｜29寸条屏：探索

### 让观众上手玩懂一处细节

29寸条屏以横向画幅承载三维细节、长图、时间线和短任务互动。它不追求长篇阅读，而是通过滑动、旋转、放大和对比，让观众在较短时间内发现展品值得关注的细节。

### 推荐内容

- 文物三维环物与局部观察。
- 横向长图、纹饰展开图和工艺流程。
- 短时间线和路线关系。
- 器型对比、局部找寻和轻量分类任务。
- 展柜前连续信息带。

### 推荐交互

横向滑动、三维旋转、双指缩放、局部热点、答案揭示和短任务反馈。界面应针对1920 × 540原生画布设计，不能把16:9页面直接压缩到条形屏中。

## P12｜43寸常规屏：大体验信息交互

### 为内容较重的展项提供更大的体验界面

43寸常规屏是产品族中的高性能大画幅终端，适合承载高分辨率图像、复杂三维模型、综合查询、互动叙事和多人操作。它的核心不是简单放大画面，而是让更丰富的信息、更多参与者和更复杂的互动在同一界面中有序发生。

### 推荐内容

## P16｜更多尺寸选型

### 当四款标准产品不能完全匹配项目时

四款产品是当前优先推荐的标准工程模组。对于特殊展柜、狭长信息带、超大岛台或既有空间改造，可进一步评估其他尺寸和比例。

| 需求类型 | 可评估方向 | 需要确认的项目 |
|---|---|---|
| 更紧凑的精读节点 | 小尺寸常规屏 | 内容字量、触摸热区、安装深度 |
| 更长的信息带 | 其他条形屏或多屏拼接 | 分辨率、拼缝、同步和长边结构 |

非四款冻结产品均需重新确认显示模组、盖板、主控配置、结构、电气、软件画布和测试方案，不沿用标准产品交期与配置承诺。

### 安全事项

- 设备应由专业人员安装和拆卸。

## P21｜拓展产品形态

### 标准工程模组可以成为不同空间中的信息节点

拓展产品形态是在四款标准工程模组基础上形成的安装与外观变化，不等于新增标准产品型号。具体外壳、支架、线缆、散热和维护结构需要按项目设计。

|---|---|---|
| 固定式 | 与展柜、展墙、展台或护栏固定结合 | 展柜前缘、墙龛、主题墙 |

| 移动式 | 使用带轮支架、教学推车或可移动底座 | 研学、讲解、临展 |

| 嵌墙式 | 屏幕与墙面或龛体形成整合 | 主题墙、竖向探索屏 |
| 滑轨式 | 终端沿展柜或展墙移动并切换内容 | 文物组跟随精读 |
| 模块拼接式 | 多台终端按直线、折线、回字或环形组合 | 双条桌、四条桌、环形展柜 |

## P23｜空间设计与安装预留

### 空间设计阶段至少要确认六件事

1. **工程模组尺寸**：以玻璃/盖板OD作为第一轮空间预留依据。
2. **有效显示与触摸区域**：外壳包边不得遮挡显示内容和触摸边缘。
3. **承托与固定**：确认墙体、桌体、护栏和支架的承重及安装基准。
4. **散热与通风**：为背部、侧面和主要热源保留空气流动空间。
5. **走线与接口**：提前预留电源、网线、USB、音频和外接设备线路。
6. **检修与更换**：确保不拆除整组展陈家具也能维护主控、电源和线缆。

## P24｜安装和使用建议

### 让不同观众都能看见、够到并顺利操作

终端安装高度不能只由屏幕尺寸决定，还应结合观众年龄、站姿或坐姿、观看距离、界面内容和操作方式综合判断。

### 人机与空间建议

| 使用情况 | 设计建议 |
|---|---|
| 成人站立操作 | 让主要触摸区落在自然抬手范围内，避免长时间举臂 |
| 儿童使用 | 适当降低主要操作区，并避免尖角、夹手和易倾倒结构 |
| 轮椅用户 | 保留正面接近空间，将核心控件放入可达范围 |
| 多人围站 | 为肩宽、手臂动作和旁观视线保留空间 |
| 近距离精读 | 控制反光和小字号，避免屏幕角度造成颈部疲劳 |
| 远距离识别 | 标题和当前状态应在触摸前就能看懂 |

### 推荐安装高度参考

| 产品 | 参考建议 |
|---|---|
| 21.5寸常规屏 | 屏幕中心约900—1000 mm，结合斜面角度调整 |
| 29寸条屏 | 屏幕中心约900—1000 mm；信息带约950—1100 mm |
| 43寸常规屏 | 桌面岛台约800—900 mm；壁挂中心约1200—1350 mm |
| 43寸条屏 | 屏幕中心约1000—1100 mm，主要触控带约950—1350 mm |

以上为方案阶段参考，不替代现场人体工学验证和无障碍设计要求。

### 日常使用建议

- 避免将终端正对强光或高反射表面。
- 保持通道、消防和疏散空间畅通。
- 定期使用适合玻璃表面的清洁工具，避免腐蚀性液体。
- 不在屏幕和外壳上放置重物或撞击玻璃。
- 多人界面应避免单一弹窗遮满全屏，并保留旁观可读性。

## P25｜内容更新与日常运维

### 让终端在展览周期内持续可用

终端交付不仅包括设备开机，还应明确内容如何更新、版本如何识别、异常如何恢复以及哪些操作需要专业人员完成。

### 内容更新

- 使用经过确认的U盘、TF卡或网络方式导入内容。
- 每个内容包应包含名称、版本、适用机型和发布日期。
- 更新前备份当前有效版本，更新后完成图文、视频、三维和触摸检查。
- 不在展厅开放期间进行未经验证的系统和应用升级。

### 日常巡检

- 检查显示、触摸、声音和网络是否正常。
- 检查终端是否异常发热、重启或出现异响。
- 检查支架、螺丝、护栏连接和线缆是否松动。
- 检查内容版本、系统时间和自动启动是否正确。
- 清洁玻璃、外壳和通风区域。

### 异常处理

先记录时间、现象、当前页面和操作步骤，再执行规定的重启或恢复流程。未经授权不拆机、不修改系统危险设置，也不使用来源不明的安装包和存储设备。

## P26｜质量验证与项目验收

### 交付时如何判断设备达到使用要求

验收应以订单配置、确认图纸、软件版本和项目验收标准为依据。主板能够运行或单项功能能够使用，不等于整机已经完成质量验证。

| 验收类别 | 建议检查内容 |
|---|---|
| 外观结构 | 外壳、玻璃、边角、安装件、缝隙和表面质量 |
| 显示 | 分辨率、画面完整性、坏点、亮度、色彩和长时间播放 |
| 触摸 | 点击、滑动、边缘、缩放、旋转和最多10点触摸 |
| 基础应用 | 视频、图文、多图、查询、三维、常亮展示和导视 |
| 网络接口 | 网口、Wi-Fi、USB、音频和订单约定的通信接口 |
| 外接硬件 | 摄像头、扫码、读卡、传感器等项目配置 |
| 稳定运行 | 冷启动、反复开关、断电恢复、定时运行和连续播放 |
| 安装安全 | 固定、承重、防倾覆、走线、接地、散热和检修 |
| 交付资料 | 型号、配置、系统、应用、内容和说明文件版本一致 |

需要IP、防尘防水、ESD、环境温度或特殊可靠性等级时，应在项目启动阶段明确标准，并以正式检测或项目验收记录为依据。

## P27｜交付、质保与服务边界

### 标准交付内容

- 经确认的终端设备及选配硬件。
- 对应电源线、安装附件和约定线缆。
- OpenHarmony系统和基础应用。
- 已确认的内容包或演示内容。
- 产品使用、安全和基础维护说明。
- 项目配置单、版本记录和验收文件。

### 标准交付流程

```text
需求与选型确认
→ 配置和安装条件确认
→ 生产与系统部署
→ 出厂检查
→ 运输和现场安装
→ 内容与功能验收
→ 质保与运维
```

### 交付周期与质保

交付周期和质保期限根据最终标准产品政策填写。定制外观、特殊尺寸、互动程序、外接硬件和现场实施的周期及服务边界，应在项目合同或配置确认文件中另行约定。
