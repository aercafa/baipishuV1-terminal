# 文博数字体验解决方案 10个重点场景文字分镜

## 01 文物细节放大台

**场景目标**：让观众在不遮挡展柜、不离开实物视线的条件下，看清肉眼难以辨认的纹饰、铭文、工艺和修复痕迹。

**空间关系**：21.5寸终端嵌入展柜前缘或20°斜面台。屏幕、展签与实物形成清晰的一一对应关系，观众站在展柜前即可同时看到实物和数字细节。

**体验分镜**：

1. 观众靠近时首先看到文物名称、主图和“查看细节”提示。
2. 点击实物轮廓上的热点，画面放大到对应纹饰或铭文，同时保留整体位置缩略图。
3. 双指缩放或拖动查看高清图像；点击图层可切换可见光、线描、释文或修复标注。
4. 结束时呈现一句总结，并提示回看实物上的对应位置。

**交付重点**：高清图像、热点标注、释读内容、图层切换程序、展柜安装结构及屏幕与实物的编号映射。

## 02 滑轨展柜跟随屏

**场景目标**：把一组展品的说明集中到一台可移动终端中，观众通过移动屏幕选择对象，使数字内容与实物位置形成直接映射。

**空间关系**：21.5寸终端安装在展柜前水平滑轨上。滑轨设置位置识别或停靠点，终端到达对应展品区间后自动切换内容。

**体验分镜**：

1. 待机画面以简短动效提示“移动屏幕，寻找对应文物”。
2. 观众握住扶手沿展柜移动，屏幕中的定位线同步变化。
3. 到达展品停靠点后，终端给出轻量视觉反馈并显示该文物摘要。
4. 观众可继续点击查看细节；再次移动时自动返回定位状态。
5. 到达滑轨末端后，系统呈现本组文物关系和下一展项方向。

**交付重点**：滑轨结构、限位与缓冲、位置传感器、线缆拖链、内容映射表、异常位置处理及维护模式。

## 03 唐代服饰数字换装站

**场景目标**：通过服饰选择、摄像采集和整体形象反馈，让观众理解唐代服装的身份、场合、形制与搭配规则。

**空间关系**：L29终端竖向设置为服装选择界面，摄像头位于同侧视线高度；43寸终端用于展示整体形象、服饰细节和历史说明。两台终端形成明确的操作区与反馈区。

**体验分镜**：

1. 观众先从L29终端选择人物身份、场合或服饰类别。
2. 摄像头识别站位并提示调整距离，界面不进行身份识别和长期保存。
3. 观众上下滑动选择服装、发式和配饰，43寸终端同步显示整体效果。
4. 点击服饰细节，画面展开形制、材料、纹样和使用场合说明。
5. 完成后生成纪念画面，可按馆方策略扫码带走；默认不保留原始人像数据。

**交付重点**：服饰数字资产、人体与服装适配程序、摄像头与补光结构、隐私提示、纪念内容服务和数据留存策略。

## 04 历史事件证词对照屏

**场景目标**：通过事件全貌与个体证词并置，使观众理解同一历史事件中的不同位置、身份和感受。

**空间关系**：L43终端呈现事件时间线和证词关系，21.5寸终端提供个体口述内容与音频收听。两块终端邻近设置，但不形成复杂主从操作。

**体验分镜**：

1. L43终端首先显示事件的时间、地点与关键节点。
2. 观众点击人物或地点，关联的21.5寸终端切换至对应证词。
3. 观众通过耳机或定向音频收听片段，同时查看照片、档案和文字摘要。
4. 返回L43终端后，已浏览证词在时间线上被标记，便于继续比较。
5. 页面最后以事实来源和档案编号结束，不以游戏化评分处理严肃内容。

**交付重点**：时间线数据、证词音视频、档案授权、双端通信、音频设备和无障碍字幕。

## 05 文物修复拼接工作台

**场景目标**：让观众通过碎片识别、拼接和依据验证，理解文物修复不是任意补全，而是建立在材料、形制和证据基础上的专业过程。

**空间关系**：43寸终端斜面安装，承担主要拼接操作；L29终端设置在后侧或侧边，持续显示材料检测、参考器型和修复原则。

**体验分镜**：

1. 观众从破损文物和修复任务说明进入。
2. 拖拽碎片寻找相邻边缘，系统以轮廓、纹饰连续性和厚度给出提示。
3. 关键步骤完成后，L29终端同步展示真实修复依据。
4. 错误拼接不会直接判负，而是提示“哪项证据不支持当前判断”。
5. 完成后展示修复前后对照和仍然保留的不确定区域。

**交付重点**：碎片模型、拼接逻辑、证据卡片、双屏同步、斜面台体和多人触控冲突处理。

## 06 青铜器铸造流程控制台

**场景目标**：将制范、合范、浇铸、冷却、脱范和修整等工序转化为可操作的因果链，让观众理解工艺步骤及错误后果。

**空间关系**：L29终端嵌入控制台前沿，实体旋钮负责选择工序，按钮负责确认；中央可配置青铜器或模具模型，灯光对应当前步骤。

**体验分镜**：

1. 待机状态显示器物成品和“从泥料开始”的入口。
2. 旋转旋钮选择工序，屏幕焦点与实体模型灯光同步变化。
3. 按下确认后，终端播放短动画并提示温度、材料或结构条件。
4. 顺序或条件错误时，显示可能产生的缺陷，并允许返回修正。
5. 完成后，模型灯光呈现从范到器的完整结构关系。

**交付重点**：工艺脚本、动画、旋钮和按钮、灯光控制、通信协议、控制台结构和耐久测试。

## 07 双人文物拼图对战屏

**场景目标**：让两位观众在竞争和即时反馈中主动观察文物轮廓、纹饰和构图，而不是只完成抽象拼图。

**空间关系**：独立展柜或中央装置两侧各设置一台L43终端，屏面最高点约1000mm。双方能够看见中央实物或复制品，但操作互不遮挡。

**体验分镜**：

1. 两侧观众分别选择同难度任务，倒计时同步开始。
2. 观众横向拖动碎片并旋转，屏幕持续显示完成度和剩余时间。
3. 完成关键区域时，中央装置灯光指向实物的对应部位。
4. 一方完成后，双方界面同时展示结果、观察要点和正确结构。
5. 系统可记录匿名场次与完成时间，但不形成公开个人排名。

**交付重点**：双端同步、题库、计时与比分、灯光联动、中央展柜结构和网络断开降级逻辑。

## 08 历史线索四方解谜桌

**场景目标**：通过四组不同证据引导小组协作，完成对历史人物、事件或考古结论的共同判断。

**空间关系**：4台L29终端围合成回字形，中部放置实体模型、档案复制品或投影。每一侧承担不同证据类型。

**体验分镜**：

1. 四侧分别获得器物、文献、地图和人物证词线索。
2. 每组完成短任务后，将有效线索推送到中央共享区。
3. 四组需要讨论并选择共同结论；任何一侧不能独立完成。
4. 系统根据证据完整度提供反馈，并解释哪些证据支持或反驳结论。
5. 任务结束后生成小组推理路径，供教师或讲解员复盘。

**交付重点**：四屏同步、触摸方向映射、证据题库、中央装置、教师控制和断线恢复。

## 09 沙盘方位观察终端

**场景目标**：让观众通过转动真实终端改变数字观察方向，把沙盘中的建筑、地形、规划与历史数据对应起来。

**空间关系**：10m×10m沙盘外围设置若干21.5寸终端。终端固定在金属立柱和万向节或双轴结构上，编码器或陀螺仪输出朝向数据。

**体验分镜**：

1. 观众握住扶手转动终端，屏幕中的视锥在沙盘平面上同步变化。
2. 对准某一建筑群后，画面叠加复原影像、规划关系或人流热度。
3. 继续改变俯仰角，可从地面视角切换到总体规划视角。
4. 点击热点查看建筑功能、年代和变迁，但不脱离当前方位。
5. 离开后终端自动回到总览和操作提示状态。

**交付重点**：旋转机构、角度传感、坐标映射、沙盘数据、增强视觉程序、限位与防夹手设计。

## 10 观众策展发布台

**场景目标**：让观众从馆藏中选择对象、建立关系并表达主题，以策展行为完成对参观内容的主动重组。

**空间关系**：43寸终端采用斜面或桌面安装。周边保留两至三人讨论空间，可配置NFC研学卡或二维码作为结果接续媒介。

**体验分镜**：

1. 观众选择一个策展命题或自行选择主题词。
2. 从馆藏卡片中选择三至五件对象，拖拽调整顺序和空间关系。
3. 系统提示年代冲突、主题关联或缺少的信息，但不替代观众判断。
4. 观众添加标题和简短说明，预览自己的数字展墙。
5. 发布前完成内容安全过滤；结果可在馆内轮播或生成二维码带走。

**交付重点**：馆藏内容库、推荐与校验规则、排版模板、内容审核、发布平台和数据保留策略。
