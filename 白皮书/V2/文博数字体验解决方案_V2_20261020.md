## P03｜白皮书任务

# 面向文博场景的系列化体验解决方案

文博数字体验解决方案以观众体验为起点，将终端设备、互动结构、界面内容、数据管理与项目服务组织为完整的产品体系。四款标准终端通过模块化设计，覆盖展柜、展墙、信息带、互动桌、沙盘及研学教育等文博场景，并以国产系统、信息安全与运营平台支撑长期运行。

本手册提供经过整合的场景方案、终端配置和交付内容，帮助项目团队快速建立专业、统一且可持续运营的数字体验。读者无需从零组合设备，可直接理解不同场景中观众如何使用、终端承担什么角色，以及项目需要交付哪些软硬件与服务。

终端不是孤立屏幕，而是连接展品、内容、空间、观众和运营服务的数字信息节点。方案价值首先体现在观众理解与行为体验，其次才体现为硬件配置和工程实现。

## P04｜产品族定义

# 产品族定义

文博交互信息终端产品族是面向博物馆、纪念馆、科技馆及文化展示空间开发的系列智慧信息交互终端。产品族以四款标准终端为稳定基础，以场景化的软件内容、互动结构和项目服务形成完整解决方案。

| 核心特征 | 产品含义 |
|---|---|
| 文博应用场景全覆盖 | 覆盖展柜、展墙、信息带、互动桌、沙盘、研学和参观延续等环节 |
| 设备模块化 | 标准终端与安装结构、交互模块和外观系统形成受控组合 |
| 系统国产化 | 采用国产ARM架构处理器、OpenHarmony和团结引擎技术路线 |
| 信息安全化 | 通过本地运行、权限、版本、更新和数据策略控制项目风险 |
| 运营平台化 | 支持内容资源、应用版本、设备状态和发布记录的持续管理 |

产品族不以设备数量定义价值。每个场景只配置完成体验所必需的终端、结构和模块，并由设计团队统一完成方案深化。

## P05｜文博应用覆盖

# 文博应用覆盖

产品族围绕观众完整旅程组织能力。进入展区前，数字内容帮助建立期待；走近展项时，终端承担主题识别和操作提示；停留后，触摸与拓展模块帮助观众进入细节、比较、推理与协作；离开展项后，进度、推荐和数字纪念内容使体验继续延伸。

| 应用阶段 | 典型需求 | 解决方案响应 |
|---|---|---|
| 展览参观 | 识别主题、理解展品、查看细节、建立关系 | 展柜精读、信息带、时间线、长卷、地图、三维和专题互动 |
| 教育活动 | 任务、协作、讨论、验证和复盘 | 对战、拼接、研学卡、控制台、移动讲解和小组共创 |
| 参观延续 | 收藏、总结、分享和继续阅读 | 策展结果、二维码、纪念内容和线上延伸入口 |

场景设计遵循“先看见、再读懂、再上手、再深入”的顺序。任何互动只有在能够帮助观众理解内容时，才进入正式方案。

## P06｜模块化终端体系

# 模块化终端体系

四款标准终端提供稳定的显示、触摸、计算、连接和基础系统能力。项目以终端为基础，根据推荐场景配置空间结构、互动模块、软件内容和运营服务。模块化的目的不是增加自由组合，而是使经过验证的方案能够在不同展览主题和空间中复用。

| 组成 | 主要内容 | 管理方式 |
|---|---|---|
| 标准终端 | 21.5寸终端、L29终端、43寸终端、L43终端 | 标准规格与版本管理 |
| 空间结构 | 展柜嵌入、斜面台、护栏、滑轨、旋转支架、移动支架 | 项目工程图与结构验证 |
| 互动模块 | 旋钮、按钮、NFC、摄像头、位置与接近传感器 | 场景配置与接口验证 |
| 软件内容 | UI、互动程序、数字内容、三维、任务与多语言 | 项目内容包与应用版本 |
| 数据运营 | 内容资源、发布、设备状态、更新与日志 | 权限、版本和运维机制 |

## P07｜国产系统与信息安全

# 国产系统与信息安全

产品采用国产ARM架构处理器、OpenHarmony操作系统和团结引擎开发框架，形成面向文博与信创项目的国产软硬件路线。技术路线覆盖终端运行、互动程序、内容资源和设备管理，并为后续适配、维护和升级保留明确边界。

信息安全从项目需求阶段开始设计。终端可采用本地离线运行或受控网络运行；应用、内容和配置通过版本记录管理；外接存储、维护入口、账号权限和远程更新按照馆方安全策略开放。涉及摄像、身份介质或观众生成内容时，应单独确定采集范围、用途、留存时间、删除机制和授权提示。

公开白皮书说明能力原则，不披露屏幕模组、主板和其他供应商的具体品牌与型号。

## P08｜运营平台与全周期服务

# 运营平台与全周期服务

文博数字体验需要在开馆后持续运行。产品族通过统一内容对象、机型适配模板、应用版本和设备配置，支持图文、视频、音频、三维模型、多语言及互动题库的持续更新，减少不同终端分别维护造成的版本漂移。

项目服务贯穿需求诊断、场景匹配、方案深化、设计开发、测试验证和部署运营。交付后可根据项目范围提供内容更新、缺陷修复、设备巡检、版本升级、数据维护和运营分析。

运营平台可按项目配置内容资源、发布记录、设备状态、权限和日志。需要联网或接入馆级系统时，应在项目启动阶段确认网络边界、接口方式和数据责任。

## P10｜旗舰场景01 方案

# 唐代服饰数字换装站

服饰数字换装站不是单纯的拍照装置，而是一套围绕身份、场合、形制和搭配规则展开的服饰理解体验。L29终端竖向设置，承担服饰选择和步骤提示；43寸终端展示整体形象、局部细节与历史说明；摄像头只在明确提示后采集体验所需画面。

观众先选择人物身份或场合，再依次选择服装、发式和配饰。每次选择都会同步更新整体效果，并解释相应服饰为何适合当前身份与场合。完成后可生成纪念画面，是否允许扫码带走及保存多长时间，由馆方项目策略确定。

**解决方案组成**：L29终端、43寸终端、摄像头与补光结构、双屏互动程序、服饰数字资产、隐私提示、纪念内容服务和现场集成。

> **推荐图片位 P10-01｜换装站等距总图** 标出竖向选择终端、整体反馈终端、摄像头、站位区和观众视线。

## P11｜旗舰场景01 体验流程

# 从选择服饰到理解制度

1. 选择身份或场合，界面说明本次体验的历史边界。
2. 在L29终端上下滑动，选择服装、发式和配饰。
3. 43寸终端同步显示整体效果，并标出形制和纹样重点。
4. 点击细节，查看材料、用途和搭配规则。
5. 生成纪念画面并结束，人像数据按馆方策略清理。

体验的核心不是“像不像本人”，而是“选择是否符合历史语境”。系统应清楚区分史料依据、推测性复原和视觉演绎，避免把单一复原结果表述为唯一事实。

**交付摘要**：终端2台、摄像与补光、定制台体、服饰资产、双屏软件、内容管理、隐私与数据策略、测试部署及培训。

## P12｜旗舰场景02 方案

# 双人文物拼图对战台

两台L43终端分置中央展柜或主题装置两侧，形成面对面或平行的双人挑战。观众在限定时间内完成文物轮廓、纹饰或构图拼合，系统通过进度、比分和中央装置反馈保持对战节奏。

拼图素材直接来自展品内容。完成关键区域时，中央灯光指向实物对应位置；结束后，双方同时看到正确结构和观察要点，使竞争结果转化为知识反馈。系统可记录匿名场次和完成时间，不设置公开个人排名。

**解决方案组成**：2台L43终端、双侧台体、同步程序、题库、计时比分、中央展柜或模型灯光、网络与现场联调。

> **推荐图片位 P12-01｜双侧对战场景总图** 画出中央展柜、两侧L43终端、两名观众和比分反馈关系。

## P13｜旗舰场景02 体验流程

# 以竞争促进观察

1. 两位观众分别选择相同难度，系统同步进入倒计时。
2. 观众横向拖动并旋转碎片，画面持续显示完成度。
3. 完成关键纹饰时，中央装置给予对应位置提示。
4. 一方完成后，双方界面同时停止并展示结果。
5. 系统解释文物结构、纹饰关系和观察方法，引导观众回看实物。

当其中一侧断线或无人参与时，系统可切换为单人计时模式，保证展项继续使用。题库根据年龄和展览主题分级，难度差异通过碎片数量、旋转限制和提示方式实现。

**交付摘要**：双终端、同步与降级逻辑、题库与知识反馈、灯光接口、结构安装、稳定性测试和运营配置。

## P14｜旗舰场景03 方案

# 沙盘方位观察终端

沙盘外围设置若干21.5寸终端。终端通过金属立柱、万向节或双轴结构支撑，观众握住扶手转动终端，屏幕朝向与沙盘方位实时对应。对准建筑群或地形区域时，数字内容叠加复原场景、规划关系、历史数据或人流热度。

这种体验把“旋转设备”转化为明确的观察行为。终端既是信息屏，也是面向沙盘的数字观察器。画面始终保留当前方位和视锥，避免观众在数字内容中失去与实体沙盘的关系。

**解决方案组成**：21.5寸终端、立柱与双轴结构、角度传感、坐标映射、沙盘数据、增强视觉程序、限位与防夹手设计。

> **推荐图片位 P14-01｜沙盘观察系统总图** 表现沙盘、外围终端、观众旋转动作、视锥和数字内容映射。

## P15｜旗舰场景03 体验流程

# 转动终端改变观察方向

1. 观众握住扶手，屏幕提示转动设备寻找目标区域。
2. 终端角度变化，沙盘中的数字视锥同步移动。
3. 对准建筑群后，画面加载对应的复原、规划或数据图层。
4. 调整俯仰角，在街区视角和总体规划视角间切换。
5. 离开后终端自动返回总览和操作提示状态。

项目需要通过真实结构样机验证阻尼、限位、线缆寿命、传感精度和儿童误操作。多台终端同时使用时，各自保持独立视角，不互相抢占沙盘内容。

**交付摘要**：旋转结构、传感器、标定工具、沙盘坐标数据、应用与内容、异常恢复、结构安全测试和现场校准。

> **推荐图片位 P15-01｜角度映射步骤图** 以三个终端角度对应三个沙盘区域，并标出限位和视锥。

## P16｜旗舰场景04 方案

# 滑轨展柜跟随屏

21.5寸终端安装在展柜前水平滑轨上。观众移动终端，使屏幕对准某件文物；位置传感器识别停靠点后，界面自动切换为对应内容。数字说明由此与实物位置保持直接联系，适合文物数量较多、展柜前空间连续的展项。

屏幕移动时显示定位线和文物编号，到达有效区域后以轻量动画确认。进入详情后可查看纹饰、铭文和关联器物；再次移动时，系统退出详情并返回定位状态。

**解决方案组成**：21.5寸终端、滑轨、限位与缓冲、位置传感、线缆拖链、展品映射程序、内容资源和展柜集成。

## P17｜旗舰场景04 体验流程

# 移动设备选择文物

1. 待机状态提示“移动屏幕，寻找对应文物”。
2. 观众握住扶手沿展柜移动，定位线同步变化。
3. 到达停靠点，终端显示文物摘要和对应关系。
4. 点击热点进入细节、铭文或纹饰释读。
5. 移动到下一位置，系统自动回到定位状态并切换对象。

## P51｜文博用户体验设计体系

# 文博用户体验设计体系

产品族根据文博项目经验、观众行为观察和用户旅程分析，形成适用于博物馆场景的体验设计体系。项目界面不是套用固定菜单，而是根据展陈主题、观众类型、终端形态和体验任务进行定制开发。

| 观众阶段 | 体验问题 | 设计响应 |
|---|---|---|
| 走近展区 | 这里讲什么，是否值得停留 | 远距标题、主题锚点和展品关系 |
| 识别终端 | 能否操作，能够获得什么 | 可交互暗示、明确入口和待机状态 |
| 初次操作 | 点了是否有反应，如何返回 | 即时反馈、容错和一致返回 |
| 内容浏览 | 当前在哪里，重点是什么 | 摘要、位置、进度和清晰选择 |
| 深入理解 | 如何建立关系和记忆 | 三维、对比、时间线、故事和证据 |
| 结束延续 | 是否看完，下一步是什么 | 总结、推荐、纪念内容和延续入口 |

界面始终服务三类观众：快速扫读、标准浏览和深度探索。首屏先帮助多数观众读懂，再为愿意停留的人提供深入内容。

全系终端以G+G电容触摸为基础交互，可根据推荐场景增加实体、感知、身份和空间联动模块。拓展模块需要同时完成结构、电气、通信、软件和测试闭环。

| 类型 | 模块 | 典型作用 |
|---|---|---|
| 实体控制 | 旋钮、拨轮、按钮、滑杆 | 时间选择、步骤确认、机械操作隐喻 |
| 身份媒介 | NFC卡、腕带、扫码 | 研学接续、内容收藏和结果带走 |
| 感知触发 | 接近、位置、角度、体感、手势 | 自动唤醒、滑轨映射、旋转观察和无接触操作 |
| 视听采集 | 摄像头、麦克风、耳机、定向音频 | 换装、口述历史、语音和无障碍内容 |
| 空间联动 | 灯光、模型、沙盘和多终端同步 | 将数字反馈映射到实体空间 |

交互模块不作为面向客户的自由选配清单，只在能够改善场景体验时进入项目配置。

## P54｜外观 结构与CMF定制

# 外观 结构与CMF定制

## P58｜人机工学

# 人机工学

以下建议适用于屏面相对水平面上仰20°、靠墙侧为斜面最高点的站姿操作方案。项目结构不同时，应重新计算并通过1:1模型验证。

| 使用群体 | 斜面最高点 | 建议眼睛至屏幕中心距离 | 设计重点 |
|---|---:|---:|---|
| 青少年为主，约9—15岁 | 950—1000mm | 约450—650mm | 高频操作靠近前缘，减少持续前伸 |
| 成人为主 | 1000—1050mm | 约550—750mm | 保持自然落手，避免耸肩 |
| 成人与青少年混合 | 建议约1000mm | 按混合人群验证 | 兼顾视线、触达与通行 |

普通站姿体验应在终端正面边缘之外预留不小于900mm净深；成人、青少年和无障碍混合使用时，建议不小于1200mm。身后通道不得计入体验净深。

## P59｜安装和使用建议

# 安装和使用建议

安装前应根据墙体、展柜、台体、护栏或支架确认承重与固定方式，并预留电源、网络、声音和外设线路。设备需要保留散热、空气流动、检修和部件更换空间；移动与斜面方案应防倾覆、防夹手并控制玻璃受力。

终端应避开强光、反射材料和主要视线中的眩光源。操作区、通道、消防和疏散空间必须保持畅通。清洁时使用适合玻璃和外壳表面的工具，避免液体进入接口和缝隙，不在屏面或外壳上放置重物。

多人或多屏场景还需统一安装基准、屏间距离、亮度、内容同步和断线降级逻辑。
