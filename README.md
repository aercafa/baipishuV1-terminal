# 四款文博信息交互终端产品手册

本项目围绕四款标准终端，编制面向馆方、采购和展项／空间设计师的“智慧交互体验体系产品”手册。产品体系承担内容延展、讲解、体验增强和业务拓展，配套定制、软硬件协同设计、一体化实施与运营支持。

## 从哪里开始

1. [HANDOFF](HANDOFF.md)：当前断点、可执行的下一步和禁止误操作事项。
2. [长期记忆](项目记忆/项目长期记忆.md)：已确认需求与编辑习惯。
3. [资料索引](项目记忆/资料索引与版本关系.md)：按问题查资料，不需遍历文件夹。
4. [配置基线](项目记忆/配置基线与待核实项.md)：四款参数、基础能力和证据边界。
5. [仓库配置与接续说明](项目记忆/仓库配置与跨电脑接续说明.md)：迁移范围、检查方法与换电脑流程。

## 当前阶段

V2是历史成果与素材，不是已通过的最终产品逻辑。V3目前只完成总结、交接和编制计划；接下来先确认产品定义与分类，再确定目录和正文。此轮文件整理不会自动开始V3写作。

最新历史成果：[V2 Word](白皮书/V2/文博数字体验解决方案_V2_初稿_20261022.docx)。为方便代理检索，另有从该文件直接提取的[文字快照](项目记忆/V2现存Word文字快照_20261026.md)，它不是可以直接回写Word的编排源文件。

## 目录与边界

- `白皮书/`：保留原有相对路径，包含V0.1、V1、V2与V3历史资料。
- `交接报告/`：工程与产品定义依据，含已去噪复盘和观众体验研究副本。
- `项目记忆/`：可跨聊天／跨电脑读取的显式项目记忆，不是完整聊天记录备份。
- `tools/`：白名单审核和文字提取工具，不含历史文档覆盖脚本。

不纳入SVG生成工程、自动化队列、渲染缓存、RHINO AI建模与插件开发。白皮书已有PNG和Word内嵌图片仅作既有文档资产保存，不意味着恢复制图工作。

历史资料可能包含已废止名称、旧参数与工程内部信息。公开使用时必须按当前记忆和证据逐项核对。项目仓库建议私有，公开传播的是另行批准的手册。
