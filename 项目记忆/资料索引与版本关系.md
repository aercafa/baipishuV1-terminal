# 资料索引与版本关系

本页用仓库相对路径建立接续入口。旧档案可能保留原电脑路径，运行和引用应优先使用本索引。未迁入的原始工程资料不伪装成可用文件。

## 接续优先级

1. [根HANDOFF](../HANDOFF.md)：当前工作状态与下一步。
2. [长期记忆](项目长期记忆.md)和[决策演变](决策与口径演变.md)：最新要求与旧口径覆盖关系。
3. [配置基线](配置基线与待核实项.md)：编辑数值、测试范围及发布缺口。
4. 根据问题读取下列历史文件；不每次整库遍历。

编辑方向以最新用户确认优先。工程事实另以对应版本正式规格、实测与审批优先；两种优先级不能混用。
