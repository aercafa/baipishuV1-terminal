## §1 大定义：什么是交互信息终端

本项目中的终端，统一定义为：

> **以视觉显示为主、以信息传达为核心、以交互作为深层内容入口、以可变内容系统为支撑的交互信息终端。**

**它不是**：

- ❌ 单一触摸查询机（那是把电脑塞进壳）
- ❌ 静态说明牌（那没有内容深度）
- ❌ 纯灯箱式信息板（那没有交互入口）
- ❌ 单次项目拼装设备（那不能复用、不能更新）

**它的本质**：嵌入博物馆展陈空间、把展柜/墙面/岛台/信息带中的静态信息，转化为**可分层阅读、可触摸探索、可多人共览、可持续更新**的展陈信息界面。

### 1.1 五个定义关键词

| 关键词 | 含义 |
|---|---|
| **视觉** | 终端首先是被"看见"和"阅读"的，先承担视觉传达，而不是复杂操作 |
| **信息** | 本质不是炫技交互，而是内容表达——把展品/导览信息转成可理解的展示形式 |
| **交互** | 不是纯显示牌，必须让观众上手、触发、切换、进入 |
| **可变** | 内容可更新、可分级、可按身份/场景/终端类型变化 |
| **系统化** | 不是独立件，而是一套后台内容与服务体系的前端使用端 |

### 1.2 产品不是"给屏幕选内容"，而是"给空间定信息节点"

终端首先是展陈空间中的视觉信息节点，必须和文物、展柜、墙面、信息带形成清晰关系。

## §2 产品逻辑：先看见 → 再读懂 → 再上手 → 再深入

这四步是**判断一切方案的标尺**。顺序不可颠倒。

| 阶段 | 要解决的问题 | 对应设计优先级 |
|---|---|---|
| **先看见** | 终端在空间里是不是一个清晰的视觉信息节点？ | 视觉呈现是否成立 |
| **再读懂** | 信息层级清不清楚？ | 名称→年代→器型→用途→铭文→纹饰→关联器物 |
| **再上手** | 交互能不能自然进入？ | 触摸是入口，不是炫技 |
| **再深入** | 深层内容有没有服务理解？ | 文物→展项组→历史脉络→器型关系 |

**用法**：任何"交互很炫，但信息没变清楚"的方案，用这把尺子直接砍掉。

**补充验收集（新增）**：四步每一步都要能被验证——

| 阶段 | 验收问题 |
|---|---|
| 先看见 | 5 米外能否识别这是"信息终端"而不是装饰？（43" 条屏适用） |
| 再读懂 | 首屏 3 秒内能否说出"这是什么、能做什么、从哪开始"？ |
| 再上手 | 首个有效操作是否需要学习？（目标：零学习） |
| 再深入 | 完成一次深层浏览后，观众能否说出一个具体的新信息？ |

## §3 分类轴：观看关系（替代"阅读距离"）

### 3.1 分类轴的变更

| | 旧轴（2026-07-15 口径） | **新轴（本文档口径）** |
|---|---|---|
| 依据 | 阅读距离（30–80cm / 0.8–2m / 2–5m） | **观看关系**（几人看 / 看多久 / 看多深） |
| 结果 | A 精读 / B 扫读 / C 引导 | ① 精读 / ② 探索 / ③ 协作 / ④ 共览 |
| 缺陷 | 由物理尺寸决定产品，同一尺寸无法承载两种关系 | 同一块 43" 16:9 可同时是壁挂视频屏与桌面岛台协作屏 |

### 3.2 四类观看关系

| 角色 | 观看关系 | 体验时长 | 页面深度 |
|---|---|---|---|
| **① 精读** | 1 人，近距离阅读 | 1–3 min | 3 级 |
| **② 探索** | 1 人操作，旁观可读 | 30 s–2 min | 2 级 + 反馈层 |
| **③ 协作** | 1–4 人协作 | 30 s–3 min | 3 级 |
| **④ 共览** | 2–3 人，最多 10 点触控 | 1–4 min | 2 级 + 并列对比 |

### 3.3 核心判断

> **产品的差异不由屏幕尺寸决定，由观看关系决定。**

这条判断的反向价值：它证明了终端可以按"**同骨架 + 不同模块组合 + 不同长度**"演化，而不用为每个场景重做一套产品逻辑。宽度与基本骨架标准化，长度与模块组合开放变化。

### §4.1 01 精读 · 21.5" 常规屏

| 项 | 内容 |
|---|---|
| 定位 | 单件文物的多级图文终端。更接近"可交互的文物说明位" |
| 核心场景 | 单件文物详细信息 |
| 体验时长 | 1–3 分钟 |
| 页面深度 | 3 级（识别 → 选择 → 释读） |
| 观看关系 | 1 人，近距离阅读 |
| 体验中心思想 | **先识别，再进入铭文、纹饰等细节** |
| 人机距离 | 触摸 30–80 cm |
| 推荐场景 | 单件展柜前缘、长条图文信息带、重点器物说明位 |
| 安装方式 | 嵌入安装为主，屏面与印刷信息带齐平 |
| 安装高度 | 屏幕中心 900–1000 mm |
| 页面层级 | 1 文物识别/基础信息 → 2 选择铭文、纹饰或相关器型 → 3 进入释读/放大/关联内容 |
| 界面布局要点 | 主图 + 分层信息：顶部名称/年代/器型/位置；左侧主图或 3D 视图；右侧四级信息栈；底部返回/相关推荐/语音入口 |
| 交互重点 | 点击进入下一层、局部放大、少量横向切换；**不做复杂游戏** |
| 适合内容 | 图文释读、铭文解释、纹饰放大、相关器型跳转 |
| 验收指标 | 首屏 3 秒说清"是什么/能做什么/从哪开始"；完成一次深读能说出一个具体新信息 |
| 未决项 | 安装高度缺身高分布与触控可达区依据（见 §13-4） |

### §4.2 02 探索 · 29" 条屏

| 项 | 内容 |
|---|---|
| 定位 | 特色展项互动与三维细节终端。重点不是长篇阅读，而是**可玩、可看细节、可旋转、可滑动比较** |
| 核心场景 | 特色展项三维探索 |
| 体验时长 | 30 秒–2 分钟 |
| 页面深度 | 2 级 + 反馈层 |
| 观看关系 | 1 人操作，旁观可读 |
| 体验中心思想 | **快速上手、滑动观察——把三维细节变成可玩的短任务** |
| 人机距离 | 触摸 30–100 cm，观看 0.8–2 m |
| 推荐场景 | 重点展项旁、特色器物组、三维模型体验点、小型互动游戏点 |
| 安装方式 | 嵌入展柜前信息带，或小型单独支架安装 |
| 安装高度 | 屏幕中心 900–1000 mm（交互带建议 950–1100 mm） |
| 页面层级 | 1 任务引导/手势提示 → 2 旋转、滑动、放大模型 → 3 细节反馈/完成提示 |
| 界面布局要点 | 左：展项名称/任务提示/基础信息；中：3D 模型或大幅细节；右：细节解释/任务反馈/下一观察点；底：手势控制条/进度点/快速退出 |
| 交互重点 | 短时、轻量、可玩；一人操作、旁观者能理解 |
| 适合内容 | 一件或一组特色展项互动；器物剖面、铭文纵向释读、互动问答 |
| **风险提示** | 可视画布仅 1920×540，**四区块（左信息+中模型+右反馈+底控制条）很可能装不下**，需按真实画布验证，预估压缩为二区块 + 浮层反馈（见 §13-6） |
| 未决项 | 优先做"单件三维细节"还是"展项组小游戏"（原 §7 待确认项） |

### §4.3 03 协作 · 43" 常规屏

| 项 | 内容 |
|---|---|
| 定位 | **一屏两形态**。壁挂时是视频叙事屏；桌面岛台时是 1–4 人互动游戏屏 |
| 核心场景 | 文物群分类互动 |
| 体验时长 | 30 秒–3 分钟 |
| 页面深度 | 3 级 |
| 观看关系 | 1–4 人协作 |
| 体验中心思想 | **用拖拽、分类、即时反馈建立器型和用途的关系** |
| 人机距离 | 触摸 0.8–1.5 m，识别 2–5 m |
| 推荐场景 | 展区入口视频墙、主题墙、独立桌面岛台 |
| 安装方式 | 壁挂安装，或单独桌面岛台支架安装 |
| 安装高度 | 壁挂中心 1200–1350 mm；桌面岛台 800–900 mm |
| 页面层级 | 1 任务说明/分类目标 → 2 多人拖拽、归类、协作 → 3 答案反馈/器型延伸 |
| 界面布局要点 | **壁挂模式**：大面积视频/动态叙事 + 底部时间线/章节导航 + 侧边 3–5 个主题节点。**岛台模式**：中心互动任务区 + 四周多人操作边；器物卡片拖拽到分类区 |
| 交互重点 | 壁挂轻触选章节；岛台强调拖拽、分类、协作、即时反馈 |
| 适合内容 | 壁挂：器型演变、墓葬礼制、展区主题视频。岛台：器型连连看、地图探索、多人桌面游戏 |
| **未决项** | ① 壁挂视频模式**本轮不展开**，仅锁定"桌面岛台多人互动游戏"主场景。② 一屏两形态是否拆为两款 SKU（见 §13-2） |

## §5 安装场景与交互方式（24 场景）

来源：2026-08-21《四款触摸终端安装交互清单》。本文档按"观看关系"重排，并按固定式/可移动式标注。

### §5.1 21.5" 常规屏（精读）· 6 场景

| 编号 | 类型 | 场景 | 安装方式 | 人与空间关系 | 交互方式 |
|---|---|---|---|---|---|
| 21-A | 固定式 | 展柜前缘固定嵌入 | 嵌入展柜前缘或展台边缘，盖板齐平或略后退 | 单人站在文物前 30–80cm 低头阅读 | 点击、翻页、局部放大、返回 |
| 21-B | 固定式 | 展台边缘斜面屏 | 嵌入低展台斜面，屏面上仰 10–20° | 站在展台边，手自然下落触摸 | 点击、滑动、短视频播放、细节切换 |
| 21-C | 固定式 | 墙龛式单件说明屏 | 嵌入展墙小龛、布题板侧边 | 站立平视或微低头，30–100cm | 点击、章节切换、图文分层 |
| 21-D | **可移动式** | 滑轨跟随式精读屏 | 展柜前水平滑轨，可沿一组文物移动 | 拖动屏幕对准某件文物，内容随位置切换 | 滑动定位、点击展开、自动识别停靠点 |
| 21-E | 固定式·创意 | 展柜转角双向精读屏 | L 形展柜或转角展墙交汇处，服务两条动线 | 两侧观众都能看到 | 点击、左右分区、导览下一件 |
| 21-F | **可移动式·创意** | 讲解员移动精读屏 | 带轮讲解支架或教学推车 | 讲解员推到展柜前，围观者共同看 | 讲解员控制、触摸标注、二维码带走 |

### §5.2 29" 条屏（探索）· 6 场景

| 编号 | 类型 | 场景 | 安装方式 | 人与空间关系 | 交互方式 |
|---|---|---|---|---|---|
| 29-A | 固定式 | 展柜前横向互动带 | 横向嵌入展柜前缘、护栏内侧或展墙底部信息带 | 30–100cm 触摸，旁人可看 | 横向滑动、3D 旋转、细节放大、翻翻卡 |
| 29-B | 固定式 | 竖向嵌墙窄屏互动点 | 条屏旋转竖装，嵌入展墙窄槽 | 正对墙面站立，屏幕像竖向互动门 | 上下滑动、模型旋转、纵向剖面浏览 |

## §6 设计约束

原 5 条（2026-08-14 版，保留）：

1. **首屏必须让观众立即知道"这是什么、可以做什么、从哪里开始"。**
2. **首屏短句化**；释读、年代、器型关系等放到深层页面。
3. **保留旁观可读性**：主操作者触摸时，旁观者仍能理解当前状态。
   —— 这是四款终端里最容易被忽略、但最难做对的一条。
4. **四款终端不强行套用同一页面结构**——精读/探索/协作/共览各自成立。
5. 43" 常规屏本轮只锁定"桌面岛台多人互动游戏"主场景，**壁挂视频模式另行展开**。

**新增第 6 条**：

6. **多人场景必须先定义"谁的屏幕"**。协作（1–4 人）与共览（2–3 人/10 点）两类终端，任何单一弹窗式详情层都会破坏多人并行——详情必须以**并列、分区或浮层不遮全屏**的方式呈现。

> 本章填补产品定义的最大缺口：大定义里的四类模块，此前只在"显示"一类上落到四款终端。

### §7.1 分配表

### §7.2 模块的主次关系

四类模块不是并列堆砌，优先级为：

1. **显示模块是基础** —— 决定"能不能看见、看不看得懂"
2. **人机交互模块是入口** —— 决定"能不能上手"
3. **连接模块是增强与延续** —— 决定"能不能带走、能不能延续"
4. **声音模块是辅助与特定场景增强** —— 决定"能不能被引导、能不能被确认"

### §7.3 【产品拓展选项】概念与需求（不展开实现）

以下为**未来开发事宜**，本节仅登记概念与需求，作为白皮书中的产品拓展选项。

| 拓展选项 | 概念 | 需求（要解决什么） | 适用终端 |
|---|---|---|---|
| **旋钮 / 拨轮** | 物理旋转件替代或补充触摸翻页，降低屏幕指纹污染，形成物理记忆 | 需明确：装在什么位置（屏幕侧边/下方/面板外延）· 与触控的分工（翻页/切换/调节）· 是否所有终端都要 · 与安装母题（§5）的配合 | 全部四款 |
| **接触式旋钮组** | 舵盘/滑动条等实体控件 | 同上，且需明确是否能与玻璃盖板一体开孔 | 待定 |
| **非接触式（接近感应）** | 观众靠近时唤醒/高亮入口 | 需明确：触发距离 · 与"先看见"目标的关系（是替代还是补充视觉吸引） | 43" 条屏优先 |
| **NFC / 身份介质** | 手机触碰或卡片/手环识别 → 内容解锁、收藏带走、体验延续 | 需明确：支持的介质（NFC/BLE/卡片）· 能带走什么（书签/收藏/研学记录）· 与馆方会员体系的关系 | 全部四款 |
| **手势互动** | 无接触操作 | 需明确：识别率 · 理解成本 · 是否会干扰旁观可读性 | 待定 |

> **本阶段结论**：以上均不进入本阶段产品定义范围，仅登记为产品拓展选项。**四款终端本阶段的交互全部落在触控上**（见 §5 的 24 个场景）。

## §8 内容分层规则

### §8.1 内容四层结构

| 层 | 回答的问题 | 承载位置 |
|---|---|---|
| **L1 主题层** | 这里讲什么？（远距识别、第一眼吸引） | 首屏 |
| **L2 摘要层** | 我为什么要停下来？（快速阅读） | 首屏或紧邻层 |
| **L3 详情层** | 这件展品到底是什么？（基础理解） | 第二层 |
| **L4 关联层** | 还有什么可以继续看？（轻量探索） | 第三层 |

### §8.2 四款终端的内容深度对应

| 终端 | 首屏（L1+L2） | 深层（L3 / L4） |
|---|---|---|
| 21.5" 精读 | 文物名称、年代、器型、用途 | L3 铭文释读 / 纹饰说明 / 器型特征；L4 相关器型 |
| 29" 探索 | 展项名称、任务提示、器物基础信息 | L3 细节解释 + 任务反馈层（**不设 L4 长链**） |
| 43" 常规 协作 | 任务说明、分类目标 | L3 答案反馈 / 器型延伸 |
| 43" 条屏 共览 | 展项组标题、观看提示 | L3 单件图文/模型/细节；并列对比（**横向并列，非纵向下钻**） |

### §8.3 内容分层原则

- **信息前置**：标题 ≤ 12 字，摘要 ≤ 40 字，正文段落 ≤ 60 字/段
- 内容按层级切换，可缓存、可预加载、可保持状态
- **可变**：内容可更新、可分级、可按身份/场景/终端类型变化
- 超时回收：无人操作后回到待机态

## §11 分辨率界面布局

> 来源：原 2026-08-14 §5。

### 1920×1080 — 21.5" 常规屏（精读）

**布局方向**：单件文物的"主图 + 分层信息"阅读界面。

- 顶部：文物名称、年代、器型标签、当前位置
- 左侧大区：文物主图或 3D 视图，支持局部放大
- 右侧信息栈：基础信息、铭文释读、纹饰说明、相关器型四个层级入口
- 底部：返回、上一层、相关推荐、语音/无障碍入口
- **交互重点**：点击进入下一层，局部放大，少量横向切换，不做复杂游戏

### 3840×2160 — 43" 常规屏（协作）

**布局方向**：同一规格下保留两种界面范式。

- **壁挂视频模式**：大面积视频或动态叙事画面，底部为时间线/章节导航，侧边保留 3–5 个主题节点
- **桌面岛台模式**：中心为互动任务区，四周为多人操作边；器物卡片可拖拽到分类区，适合 1–4 人同时参与
- **交互重点**：壁挂模式轻触选择章节；岛台模式强调拖拽、分类、协作和即时反馈

### 1920×540 — 29" 条屏（探索）

**布局方向**：特色展项的横向探索界面。

- 左侧：展项名称、任务提示、器物基础信息
- 中央：3D 模型或大幅细节图，支持旋转、滑动、放大
- 右侧：细节解释、任务反馈、下一处观察点
- 底部：手势控制条、进度点、快速退出
- **交互重点**：短时、轻量、可玩；适合一人操作、旁观者理解
- ⚠️ **待验证**：540px 高度能否容纳以上四区块

### 3840×720 — 43" 条屏（共览）

**布局方向**：展项组的横向并列与多人共览界面。

- 顶部：展项组标题、观看提示、分类筛选
- 中部：6–10 件文物横向排列，形成线性时间轴或器型谱系
- 底部：对比阅读栏、多人触控区、分类标签、纹饰/铭文/用途切换
- **交互重点**：2–3 人同时点选，最多 10 点触控；避免单一弹窗遮挡整体线性关系

> 📌 43" 条屏已出低保真线框（2026-10-09）：P01 概览 → P02 详情 → P03 并列对比。这是四款中第一张落地的界面结构。

### A.2 产品定义再理解

当前项目不应被理解为单一的"查询机"或"电子说明牌"，而是嵌入博物馆空间的交互信息终端系统。它的核心价值不是把屏幕放进展厅，而是把展柜、墙面、岛台、信息带中的静态信息，转化为可分层阅读、可触摸探索、可多人共览、可持续更新的展陈信息界面。

建议继续沿用这条产品逻辑：

- **先看见**：终端首先是展陈空间中的视觉信息节点，必须和文物、展柜、墙面、信息带形成清晰关系。
- **再读懂**：内容应从名称、年代、器型、用途、铭文、纹饰、关联器物逐层展开。
- **再上手**：触摸不是炫技入口，而是帮助观众放大、旋转、比较、归类、选择阅读路径。
- **再深入**：深层内容服务于对文物、展项组、历史脉络和器型关系的进一步理解。
