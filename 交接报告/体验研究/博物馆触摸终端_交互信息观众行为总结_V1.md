# 博物馆触摸终端 — 交互模式、信息承载与观众行为总结

> 版本：V1 | 日期：2026-07-23
> 适用终端：3840×720（43" 48:9）/ 1920×540（29" 32:9）
> 定位：为本次双终端选型提供交互&信息设计决策依据

---

## 一、核心前提：条形屏的特殊性

两块屏幕都是超宽条形屏（32:9 和 48:9），与传统 16:9 终端有三点根本区别：

| 特性 | 传统 16:9 终端 | 条形屏 |
|------|:---:|--------|
| 信息流向 | 纵向堆叠 | **水平流动** |
| 视线路径 | 上下扫描 | **左右扫描** |
| 多人共用 | 困难（单人正对） | 自然（并排站立） |
| 物理隐喻 | 书页 | **画卷 / 时间轴 / 展柜** |

这个区别决定了下面所有的交互和信息设计思路。

## 二、信息承载模式

### 2.1 五类信息结构（博物馆终端通用）

根据全球博物馆数字终端调研，信息承载可归为五种结构：

```
┌─────────────────────────────────────────────────┐
│  1. 层级递进型        │  2. 横向浏览型          │
│  (Drill-down)         │  (Horizontal Browse)     │
│  标题 → 摘要 → 详情   │  卡片画廊 → 点击展开     │
│  适合：深度了解       │  适合：快速扫读         │
├─────────────────────────────────────────────────┤
│  3. 时间轴型           │  4. 对比探索型          │
│  (Timeline)            │  (Compare & Contrast)   │
│  横向拖动 → 时间节点   │  左/右并排 → 发现差异   │
│  适合：历史叙事        │  适合：类型学展示       │
├─────────────────────────────────────────────────┤
│  5. 空间映射型                                  │
│  (Spatial Map)                                  │
│  地图/剖面图 → 点击热点 → 弹出信息              │
│  适合：地理/建筑/考古                            │
└─────────────────────────────────────────────────┘
```

### 2.2 五类结构 × 两款终端适配

| 信息结构 | 1920×540 (29") | 3840×720 (43") | 说明 |
|----------|:---:|:---:|------|
| 层级递进型 | △ 勉强 | ✓ | 29" 纵向空间不足（540px），最多两级 |
| 横向浏览型 | ✓✓ 最佳 | ✓✓ 最佳 | 条形屏天然优势，横向滚动卡片 |
| 时间轴型 | ✓ | ✓✓ | 43" 超宽屏幕可容纳完整时间线 |
| 对比探索型 | ✓ | ✓✓ | 43" 左右并排空间充裕 |
| 空间映射型 | △ | ✓ | 29" 高度有限，地图缩放后细节丢失 |

### 2.3 信息深度分层（关键数据）

博物馆调研表明，观众按投入程度分为三类，内容应设计三条路径：

| 路径 | 停留 | 内容量 | 典型交互次数 | 占比 |
|------|:---:|--------|:---:|:---:|
| 🏃 快速扫读 | 5–15 秒 | 标题 + 一句话 | 0–1 次 | ~50% |
| 🚶 标准浏览 | 30–90 秒 | 标题 + 摘要 + 1 层详情 | 2–4 次 | ~35% |
| 🧐 深度探索 | 1–3 分钟 | 全部内容层级 | 5–10 次 | ~15% |

**设计原则**：永远先服务 50% 的快速扫读者。如果 5 秒内抓不住他，后面的 15% 深度用户就不会存在。

### 2.4 条形屏的信息布局规律

基于全球条形屏终端案例（阿姆斯特丹国立博物馆、Cooper Hewitt 交互桌、V&A 数字终端）总结：

```
3840×720 (43") 布局模板：
┌──────────────────────────────────────────────────────┐
│ 远距标题区(640×720) │        卡片画廊滚动区            │
│   单展品大字标题     │   ┌────┐  ┌────┐  ┌────┐      │
│   5m 可辨识         │   │卡片│  │卡片│  │卡片│ →   │
│   2-4个大字         │   └────┘  └────┘  └────┘      │
│                     │   每张卡片=一个信息单元          │
│  ← 固定锚点区 →     │  ← 横向滑动区（占 80% 宽度）→   │
└──────────────────────────────────────────────────────┘

1920×540 (29") 布局模板：
┌─────────────────────────────────────────┐
│  ┌────┐  ┌────┐  ┌────┐  ┌────┐ 半露出 │
│  │卡片│  │卡片│  │卡片│  │卡片│  →     │
│  └────┘  └────┘  └────┘  └────┘        │
│  全屏卡片画廊，单屏显示 3.5 张卡片       │

└─────────────────────────────────────────┘
```

### 3.2 主导交互模式详解

#### 模式 A：卡片画廊浏览（适用：29" + 43"）

```
触发：进入待机 → 自动开始卡片轮播（3s/张）
交互：横向滑动 → 卡片吸附(snap) → 点击 → 展开详情
返回：右下角固定返回按钮 → 回到画廊
```

- 来源：Cooper Hewitt 交互桌、Apple Store 产品页
- 条形屏最佳适配：水平滚动利用屏幕天然长宽比
- 关键细节：右侧必须半露出下一张卡片边缘（peek效果），暗示"可滑动"
- 每张卡片 = 一个独立信息单元（展品/主题/路线）
- 卡片内容：大图 + 6-8字标题 + 角标分类

#### 模式 B：时间轴推拉（适用：43" 最佳，29" 可用）

```
触发：进入时间轴专题 → 全屏横向时间线
交互：拖拽/旋钮平移时间线 → 节点吸附 → 点击展开事件卡片
返回：双指捏合或返回键
```

- 来源：史密森尼航空航天博物馆"互动时间线"
- 43" 优势：3840px 宽度可容纳完整历史跨度，一次看到百年
- 29" 做时间线需分段，每段一个时代，旋钮切换段位
- 节点设计：关键事件用大圆点，过渡事件用小圆点

#### 模式 C：翻翻卡 / 揭示式（适用：29"）

```
L1：卡片正面 → 线索提示（图标 + 2-3字疑问词）
交互：点击 / 旋钮按下 → 3D 翻转动画
L2：卡片背面 → 答案/解释（图文）
```

- 来源：Nintendo Switch 博物馆导览、科学中心互动展项
- 无需文字引导，图标 + 动效暗示操作
- 特别适合 29" 走读场景：路过的观众被翻转动画吸引停下来

#### 模式 D：双人分区（适用：43" 独有）

```
触发：两人同时触摸屏幕左右区域
交互：左半区独立浏览 → 右半区独立浏览 → 互不干扰
协作触发：两人同时拖拽同一物体到中间 → 触发协作内容
```

- 来源：新加坡科学中心"E3"虚拟森林
- 43" 独有优势：48:9 屏宽可自然容纳两人并排站立
- 触控分区：以屏幕中线为界，左右独立处理触控事件
- 协作模式：设置中间重叠区，需要双方同时操作时触发

#### 模式 E：旋钮焦点式（适用：29" 主打）

```
旋钮旋转 → 屏幕焦点环在卡片/菜单项之间跳转
旋钮按下 → 确认/进入
触控退化为备用通道
```

- 来源：音响设备/工业控制面板的操作逻辑
- 29" 走读场景关键：观众不想摸屏幕（手脏/社恐），旋钮提供物理替代
- 焦点环独立于触控热区，视觉上明确当前选中项

## 四、观众行为模型

### 4.1 博物馆触摸终端观众行为六阶段

```
┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐
│ 远距    │→ │ 靠近    │→ │ 试探    │→ │ 投入    │→ │ 深入    │→ │ 离开    │
│ 吸引    │   │ 识别    │   │ 接触    │   │ 使用    │   │ 探索    │   │ 带走    │
│ (5-15m) │   │ (1-3m)  │   │ (0-1m)  │   │ (0-30cm)│   │ (持续)  │   │ (离开后)│
└────────┘   └────────┘   └────────┘   └────────┘   └────────┘   └────────┘
    ↓            ↓            ↓            ↓            ↓            ↓
 大字号标题   引导动画    首次触摸     内容浏览     关联发现    二维码
 动态待机    光效提示    即时反馈     逐层深入     推荐入口    社交分享
 高亮区域    "开始了解"   0.5s响应    进度反馈     展线串联    手机延续
```

### 4.2 每阶段的设计策略

| 阶段 | 观众心理 | 设计策略 | 失败后果 |
|------|---------|---------|---------|
| 远距吸引 | "这里有什么？" | 大字标题（64-120px），动态待机内容循环 | 直接走过，不会回来 |
| 靠近识别 | "怎么用？我能碰吗？" | 引导动画/光效暗示可交互，明确"开始"入口 | 站 3 秒离开 |
| 试探接触 | "会有什么反应？" | 首次触摸立即给出视觉反馈（<100ms），不惩罚误触 | 以为坏了/不敢碰了 |
| 投入使用 | "有意思，再看看" | 内容分层递进，不一次给完，留探索钩子 | 快速浏览后离开 |
| 深入探索 | "还有什么？" | 关联推荐、进度可视化、"你可能也感兴趣" | 看完就走 |
| 离开延续 | "回去想再了解" | 二维码/手机延续、纪念卡片生成 | 出了馆就忘了 |

### 4.3 关键行为数据（来自全球博物馆研究汇总）

| 指标 | 数据 | 来源 |
|------|------|------|
| 互动展项使用率 | 30-50% 观众会使用触摸终端 | V&A British Galleries 研究 |
| 使用后满意度 | 87% 认为交互终端增强了体验 | ibid |
| 非使用者原因 | "不知道怎么用"（首因）> "不感兴趣" | Gammon, 2010 |
| 首次操作成功率 | 无引导时 < 40%，有引导动画后 > 75% | 多个博物馆可用性测试 |
| 平均停留时间 | 快扫:5-15s / 标准:30-90s / 深度:1-3min | TouchWall 2025 Guide |
| 最有效吸引手段 | 动态内容 > 大标题 > 光效 > 声音 | 多个眼动追踪研究 |
| "做了才理解" | 主动参与比被动接收的信息记忆率高 60%+ | Boston Children's Museum |
| 社交影响 | 有人使用时，其他人使用概率提高 3 倍 | 巴林国家博物馆 2024 |
| 放弃原因 Top 1 | 首次操作无反馈 | 可用性研究共识 |

### 4.4 两类条形屏的观众行为差异

| 行为维度 | 1920×540 (29") 走读场景 | 3840×720 (43") 驻留场景 |
|----------|--------------------------|--------------------------|
| 发现方式 | 路过时余光扫到 | 远距被亮度和尺寸吸引 |
| 接近速度 | 边走边看，不停 | 从远处径直走过来 |
| 操作姿态 | 侧身/路过，单手旋钮 | 正对站立，双手可触控 |
| 典型停留 | 5–30 秒 | 30 秒–2 分钟 |
| 社交模式 | 单人 | 单人为主，可双人 |
| 阅读量 | 标题级（15-25 字/屏） | 段落级（50-80 字/屏） |
| 离开原因 | 已经走过，来不及停 | 看完当前内容或被同伴叫走 |

## 五、交互模式 × 终端适配决策矩阵

基于以上分析，为两款终端推荐以下交互模式组合：

| 交互模式 | 29" (1920×540) | 43" (3840×720) | 理由 |
|----------|:---:|:---:|------|
| 卡片画廊浏览 | **P0** | **P0** | 条形屏天然优势，两款均主打 |
| 翻翻卡揭示 | **P0** | P1 | 29" 走读场景最佳交互形式 |
| 时间轴推拉 | P1 | **P0** | 43" 宽度可做完整时间线 |
| 双人分区 | — | **P0** | 43" 独有优势 |
| 旋钮焦点式 | **P0** | P1 | 29" 主力交互，43" 辅助 |
| 纯触控操作 | P1 | **P0** | 43" 大屏直接触摸体验好 |
| 接近感应唤醒 | — | P1 | 43" 远距场景适用 |
| 二维码带走 | — | P1 | 43" 深度浏览后提供 |

## 六、总结：为两款终端的设计建议

### 6.1 29" 1920×540 —— 走读信息带

**一句话定位**：让人"路过时看懂，感兴趣时停下来翻一翻"

**核心交互**：
- 自动轮播卡片画廊（非接触时）
- 物理旋钮旋转翻页（接触时）——主力
- 触控点击进入翻翻卡（深度时）

**内容原则**：
- 单屏单信息，15-25 字
- 图标 > 文字
- 不设三级深度，最多两级（卡片 → 翻翻卡）
- 不做段落文字

### 6.2 43" 3840×720 —— 引导+共览信息带

**一句话定位**：把远处的人"拉过来"，让走近的人"一起看"

**核心交互**：
- 远距大字标题 + 动态待机（5m 外）
- 走近后变为卡片画廊（1m 内）
- 触控为主，支持双人分区
- 时间轴 + 长卷式深度内容

**内容原则**：
- 双字号系统：远距 64-120px，近距 18-28px
- 可容纳段落文字（50-80 字/屏）
- 三级深度可行（画廊 → 内容 → 详情）
- 出口处提供二维码"带走"
