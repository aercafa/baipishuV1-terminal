# 博物馆交互终端用户旅程图 V1

## 1. 文档目的

本文件用于建立“博物馆交互终端”的用户旅程图，作为产品定义阶段的核心输入。

这份旅程图不只是描述观众参观流程，而是要回答以下问题：

- 观众在不同阶段分别在做什么
- 观众需要什么信息
- 观众会出现哪些痛点、焦虑和阻力
- 信息终端在不同阶段应扮演什么角色
- 哪些问题可以转化为产品机会点

本文件同时承担两个作用：

- 作为当前阶段产品定义工作的核心分析文档
- 作为后续产品定义、功能收敛、PRD 编写的上下文基线

## 2. 分析方法

### 2.1 旅程图使用的输入来源

本文件综合三类输入：

#### A. 博物馆场景与用户体验研究

来源：

- [信息带终端设计原则与理论依据v2.docx](/Users/yellowburger/Desktop/🐟/works/触摸终端调研/信息带终端调研/信息带终端设计原则与理论依据v2.docx)

重点采用：

- 博物馆是信息传播系统
- 四阶段体验旅程
- 诺曼三层体验模型 `L1 / L2 / L3`
- 必要功能体系 `F1-F4`

#### B. 品牌研究方法

来源：

- Sonos
- Teenage Engineering
- PAM
- Mappedin

重点吸收：

- PAM：旅程连续性、触点系统、信息减压
- Mappedin：信息层级、多终端同步、定位 / 导览 / 无障碍
- Sonos：低认知负担、复杂能力简单化
- Teenage Engineering：对象感、控制表面、角色化反馈

#### C. 外部旅程研究参考

重点采用的通用结论：

- 博物馆体验应看作 `before / during / after` 的整体旅程
- 用户旅程需要覆盖 `actions / needs / emotions / pain points`
- 数字与物理体验在用户眼中是同一件事

本版旅程图默认场景为：

- 博物馆常设展厅

- 终端以信息传递为主、交互探索为辅

## 4. 用户旅程主图

## 4.1 阶段一：到达前

### 用户目标

- 了解展览是否值得看
- 知道馆内大致有什么内容
- 建立参观预期
- 形成简单路线判断

### 用户行为

- 浏览官网 / 小程序 / 社交媒体
- 看展览介绍
- 看推荐内容
- 搜索热门展品
- 看场馆位置与交通

### 用户想法

- 这个展览有什么重点
- 有哪些不能错过的内容
- 我是否适合来看
- 到馆后会不会很复杂

### 用户情绪

- 期待
- 好奇
- 轻度不确定

### 用户痛点 / 焦虑点

- 不知道展览重点是什么
- 不知道哪些内容适合自己
- 对馆内路径没有概念
- 到馆后担心找不到重点

### 信息需求

- 展览主题
- 展览结构
- 重点展项
- 推荐参观方式
- 基础导览信息

### 产品机会点

- 线上预热内容与终端内容结构一致
- 到馆前提供重点展项预览
- 建立“到馆后可继续阅读”的内容接续
- 形成馆内外同一信息体系

---

## 4.2 阶段二：走近展区

### 用户目标

- 快速判断这个展区值不值得停留
- 快速识别展区主题
- 快速理解信息终端是否与展品相关

### 用户行为

- 远距离扫视空间
- 观察展区标题
- 观察亮点内容
- 顺着动线移动
- 短暂停留判断是否靠近

### 用户想法

- 这里讲什么
- 这个区域是不是重点
- 那块终端和展品有什么关系
- 这里能不能看懂

### 用户情绪

- 好奇
- 犹豫
- 选择压力

### 用户痛点 / 焦虑点

- 展区标题不够明显
- 终端不显眼
- 看不出这里是不是可交互区域
- 不知道终端与展品的关系
- 害怕靠近后内容太复杂

### 信息需求

- 展组主题
- 当前区域定位
- 可接近暗示
- 终端与展品关系提示

### 产品机会点

- 5 米外可见标题
- 待机动态提示
- 展组锚点设计
- 可交互暗示设计
- 展品与终端关系前置表达

---

## 4.3 阶段三：初次识别终端

### 用户目标

- 判断终端是什么
- 判断终端能提供什么帮助
- 判断是否值得靠近和使用

### 用户行为

- 观察玻璃表面
- 观察动态区 / 图文区
- 判断哪里可以看、哪里可以点
- 观察同伴是否使用

### 用户想法

- 这是说明屏还是交互终端
- 我是不是可以点它
- 这里能不能帮我快速理解展品

### 用户情绪

- 轻度试探
- 好奇
- 谨慎

### 用户痛点 / 焦虑点

- 终端太像设备，不像展陈的一部分
- 交互区不明确
- 息屏状态下看不出用途
- 信息和操作边界混乱

### 信息需求

- 终端用途说明
- 核心交互入口提示
- 阅读区与交互区提示
- 当前可进行的动作提示

### 产品机会点

- 控制表面设计
- 隐形触控区提示
- 参数化图案引导
- 待机态角色化提示
- 轻量“开始了解”入口

---

## 4.4 阶段四：阅读基础信息

### 用户目标

- 快速理解展品讲了什么
- 快速建立展品与文字的对应关系
- 快速抓住重点

### 用户行为

- 阅读标题
- 阅读展品名称
- 看图文对应
- 看编号对应
- 快速扫读说明
- 与同伴共同阅读

### 用户想法

- 这件文物的重点是什么
- 这段文字在说什么
- 图像和实物怎么对应
- 我现在看的内容是不是最重要的

### 用户情绪

- 稳定阅读
- 轻度认知负荷

### 用户痛点 / 焦虑点

- 字体太小
- 信息太密
- 重点不清楚
- 图文没有对齐
- 内容太专业
- 没有故事性

### 信息需求

- 主标题
- 展品名称
- 基础说明
- 图像辅助
- 重点摘要
- 展品对应关系

### 产品机会点

- 三级标题层级
- 图文双重编码
- 信息折叠 / 展开
- 快速摘要模式
- 深度阅读模式
- 多语言切换

---

## 4.5 阶段五：进入交互探索

### 用户目标

- 获得超出展板之外的信息
- 深入理解展品
- 探索隐藏内容或关联内容

### 用户行为

- 点击详情
- 切换图片 / 视频 / 3D
- 切换语言
- 打开语音
- 旋转模型
- 点击关联展品
- 返回概览页

### 用户想法

- 还有什么我没看到
- 我点了之后会发生什么
- 这和旁边展品有什么关系
- 有没有更直观的解释

### 用户情绪

- 兴趣增强
- 参与感增强
- 若反馈差则迅速挫败

### 用户痛点 / 焦虑点

- 交互不直观
- 操作步骤太多
- 点了没反应
- 不知道是否点对
- 不知道怎么返回
- 多人操作互相干扰

### 信息需求

- 当前层级提示
- 操作结果提示
- 返回路径提示
- 关联内容入口
- 下一步操作提示

### 产品机会点

- 两步触达
- 即时反馈
- 物理旋钮 / 轻实体件
- 角色化状态反馈
- 关联展品跳转
- 深层探索模式

---

## 4.6 阶段六：深入理解与停留

### 用户目标

- 建立对展品更完整的理解
- 形成自己的判断和记忆点
- 将眼前展品与更大的历史 / 文化叙事联系起来

### 用户行为

- 持续阅读深层内容
- 对比多个展品
- 看故事化内容
- 听语音
- 与同伴讨论

### 用户想法

- 这件展品真正重要在哪里
- 它和整段历史有什么关系
- 我是否理解了这件展品

### 用户情绪

- 沉浸
- 理解增强
- 若内容碎片化则疲劳

### 用户痛点 / 焦虑点

- 内容碎片化
- 缺少叙事串联
- 看了很多但没有形成整体印象
- 深层内容没有节奏

### 信息需求

- 叙事结构
- 关键故事线
- 情境还原
- 关联知识点
- 总结性信息

### 产品机会点

- 叙事化内容结构
- 时间轴 / 结构图 / 流程图
- 情境化动画 / 场景还原
- 主线叙事串联
- 本展组记忆点提炼

---

## 4.7 阶段七：离开展项

### 用户目标

- 知道是否已经看完重点
- 知道下一步看什么
- 保持观展流畅性

### 用户行为

- 结束当前阅读
- 环顾四周
- 寻找下一个展组
- 跟随动线离开

### 用户想法

- 我现在看完了吗
- 下一步应该去哪
- 我有没有漏掉重点

### 用户情绪

- 满足
- 轻度不确定

### 用户痛点 / 焦虑点

- 没有结束感
- 不知道下一步
- 不知道是否漏掉重点
- 展组与展组之间断裂

### 信息需求

- 当前进度
- 下一步建议
- 邻近展组提示
- 本组总结

### 产品机会点

- 进度提示
- 下一步推荐
- 前后展组引导
- 本组总结卡
- 探索完成反馈

---

## 4.8 阶段八：离馆后延续

### 用户目标

- 带走有价值的信息
- 回忆今天真正理解了什么
- 有机会继续了解

### 用户行为

- 扫码收藏
- 关注公众号 / 小程序
- 分享纪念图
- 离馆后回看内容

### 用户想法

- 今天最值得记住的是什么
- 我还能不能继续看
- 我是否真正理解了这段文化

### 用户情绪

- 回味
- 满足
- 或“看完就散掉”的空白感

### 用户痛点 / 焦虑点

- 没有可延续入口
- 没有形成记忆点
- 内容无法带走
- 离馆后体验中断

### 信息需求

- 本次参观总结
- 延伸阅读入口
- 后续内容入口
- 纪念性内容

### 产品机会点

- 小程序延续入口
- 个人参观记录
- 纪念图 / 纪念卡
- 延伸阅读推荐
- 继续探索入口

## 7. 旅程图对产品定义的直接启发

### 7.1 终端应被定义为旅程中的关键触点

它不是一台孤立设备，而是：

- 观众建立理解的入口
- 观众继续探索的入口
- 观众形成记忆的入口

### 7.2 终端的主要任务应是信息翻译

不是展示技术，而是：

- 把专业内容翻译为公众语言
- 把复杂知识翻译为可理解层级
- 把抽象知识翻译为可记忆体验

### 7.3 信息主导、交互辅助，是合理路径

旅程图显示，大量阶段的核心需求首先是：

- 理解
- 判断
- 确认
- 继续前进

交互不是所有阶段的主角，更多是帮助用户进入更深层内容的辅助动作。

### 7.4 状态与进度信息非常重要

用户在旅程中反复会问：

- 我现在在哪
- 我看到哪了
- 我下一步去哪
- 我有没有漏掉重点

这说明终端需要承担“状态提示”和“旅程引导”的责任。

### 7.5 离馆后延续不是附加功能，而是旅程的一部分

旅程并不在离开展项时结束。  
离馆后的延续入口，应被提前纳入产品定义。
